# TestGit Site — Simple Website

This repository folder `testgit-site` contains a small static website starter.

How to run locally

1. Open a terminal in the `testgit-site` folder.
2. Run a static server (Python 3):

```powershell
python -m http.server 8000
```

3. Open http://localhost:8000 in your browser.

Files included

- `index.html` — landing page
- `styles.css` — styles
- `script.js` — small interactivity

You can rename the folder into a dedicated repository and push it to GitHub, or ask me to scaffold a GitHub Pages workflow.
